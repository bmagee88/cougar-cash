# Cricket Climb

Local React game at `/cricket-climb`, also linked from the Games section of the home page. No backend or leaderboard. Settings and personal bests use browser local storage.

## Reading and defaults

Defaults are **kindergarten only, every subject checked, and Read aloud off**. Saved preferences, including older unversioned selections, are retained on reload; defaults fill only missing fields. Continue still restores the saved grades and subjects, with the current audio/theme preferences. Later deliberate preference changes are retained.

Read aloud automatically reads **only the question**, including the target word for a word exercise. It does not spell the missing letter or announce the grade, level, answer list, navigation controls, or jump/celebration scripts. Tap question text, a visible clue, situation text, plan title, individual instruction, or any numbered written choice to read just that item, even with automatic reading off. Choice read buttons never select an answer. New taps cancel the previous reading; answers stay locked through the original reading deadline, the current utterance, and a thinking second. Reading does not reshuffle leaves or alter scores/progress.

For pictured first/last-letter questions, voice on shows **First letter? / Last letter?** and the picture, while the spoken question names the word (for example, bed). Voice off keeps **First letter in bed?** visible. This applies across kindergarten and first grade. Early picture vocabulary likewise uses **Find the picture.** with the target spoken when voice is on, and **Find bed.** when voice is off. Spelling, sight-word, and blend questions name their target in question audio while their incomplete word remains masked; tapping a masked clue still reads “blank.” These are presentation changes, so saved questions and leaf layouts remain unchanged when audio is toggled.

Letter-name identification is an auditory quiz: its printed prompt is “Listen. Find the letter.” The target letter is spoken, and the answer leaves are not automatically named. These questions are omitted when Read aloud is off. Upper/lowercase matching remains visual; second-grade alphabet-order questions remain available silently. Keyboard letter/digit identification follows the same listening rule, while silent keyboard questions ask about key functions. If voice is unavailable, an auditory-only question is replaced with a visual challenge at the same level, preserving its safe lane.

`reading.ts` reads visible blanks as “blank,” without completing words, calculating missing digits, naming hidden instructions, or revealing missing step numbers. Each of the five compact saved levels can record its generation profile, so changing audio preserves the other questions and leaf layouts. Old saves and personal-best keys remain supported. Bests are shared across question-bank versions for the same selected game rules, so a content update cannot hide an earned best.

## Teacher checklist curriculum

The supplied K–2 computer-literacy checklist now has **nine selectable topics and 52 modular question families**, one for each requirement. See [the teacher guide](CURRICULUM.md) for grade-by-grade coverage and a generated example for every requirement. Kindergarten introduces 18, first grade adds 16 (34 cumulative), and second grade adds 18 (52 cumulative). Higher grades retain earlier practice, with roughly 60% current-grade additions and 40% review when the topic has both.

`curriculumResources.ts` contains stable requirement IDs, proposed introduction grades, topic labels, and reusable resource banks. `curriculum.ts` registers the families and builds seeded scenarios, keyboard editing, icon/function matches, search phrases/addresses, patterns, robot debugging, and loop counts. Context and numbered options are written and narrated; the leaves still contain one letter, digit, symbol, or picture. Five-leaf scenarios have four distinct distractors. All questions use a 1.5-second total answer pause; active speech must finish before the final half-second of thinking. Their text is read individually on request; number keys select the printed choice number.

Garden settings' **Practice the computer checklist** shortcut selects those nine topics. New installations start with kindergarten only, all 21 subjects checked, and automatic reading off. Existing saved selections stay intact; the earlier Computer buttons, Computer basics, and Algorithms & order remain optional classic practice with unchanged seeded generators, so saved climbs and their score keys still restore. Browser/web and creation/files use related kindergarten foundations before their checklist introduction in grade 1; troubleshooting uses asking-for-help foundations before grade 2. Questions practice knowledge; independent typing, dragging, sign-in, and device-care performance still require classroom observation.

The audit now covers all 21 skills, all four leaf counts, and all three grades, including every curriculum requirement, cumulative review, explicit wrong-step debugging, scenario reading time, and numbered-choice restoration. Five small local SVG teaching icons in `public/cricket-climb` supply a tablet, trackpad, crossed-out eye, centered lines, and captions.

## Play

- The opening offers **Keep hopping!** to continue the latest saved climb and **A fresh little climb** to start over with new questions. Continue is disabled until a climb has been started. Both choices enable browser audio. Automatic narration reads only the question; individual written choices have separate tap-to-read buttons. Answers unlock after narration and half a second of thinking. With narration off, every question has a 1.5-second total wait (one reading second plus half a thinking second).
- Returning players find Pip on the ground. **Keep hopping!** triggers a special crouch, speedy super-jump with a scrolling ruler, stretchy cricket and motion trails, then a soft landing at the exact saved position. Even high climbs take only a few seconds with narration off. Questions and choices stay hidden and locked until landing; normal reading and thinking time then begins. The jump does not advance progress, change saved answer layouts, or affect personal bests. Reduced-motion preferences replace the fast ascent with a brief transition.
- Tap a leaf (or press its numbered keyboard shortcut). Pip jumps there, waits three full seconds, then every incorrect leaf at that level opens. A wrong choice falls vertically to the nearest correct leaf in that lane, or to the safe ground. The next question is immediately above the landing.
- Questions and answer sets stay fixed throughout a run. Retrying a level rearranges its choices. Refresh returns to the opening choices; **Keep hopping!** restores the same seed, current question, answer order, standing position, and saved game rules. Current voice, sound, and theme preferences are kept. **A fresh little climb**, **New climb**, or saving different game rules during play creates a fresh seed. Replaying narration and changing cosmetic/audio settings keep the question and layout.
- The single rolling save contains only **five compact level records**: the current question and the four levels below it (fewer near the ground). It also stores the seed, game settings, personal progress, and recent spider-attempt metadata. Older question content and terrain are recreated on Continue; older layouts are not retained. Rebuilt terrain preserves limited-fall safety, and random falls can still reach the ground. The save updates at each question and as soon as an answer resolves; a refresh during a jump or suspense resumes the unanswered question, while a refresh after the reveal resumes at the resolved landing and next question. Starting over replaces the rolling save and preserves personal bests.
- Sessions already open in the older version have no progress save to restore. Saving begins when playing the updated version; existing personal-best records are retained.
- Limited fall ensures every wrong lane has a catch within the number of answer leaves. The first rows use every lane before repeating; subsequent layouts preserve the catch-distance invariant, including on retries. This can constrain the correct answer's lane on a retry; distractors still rearrange when possible. Random fall imposes no catch-distance constraint.
- Platforms above a landing close. Lower incorrect platforms stay open, and lower correct platforms remain available to catch a fall. Only nearby rows render, so the ruler can keep climbing.
- Patches contain 5, 6, 7, 8, … questions. Fanfare celebrates the first arrival at each patch in a run. **Kindergarten**, **1st grade**, and **2nd grade** have separate checkboxes. A run starts immediately at the lowest checked grade, advances to the next checked grade after six patches, and stays within the highest checked grade. With all three checked, first grade starts at patch 7 (level 46) and second grade at patch 13 (level 127). With only second grade checked, second-grade questions start at level 1. Unchecked grades are skipped. Grade labels and fanfare announcements follow the selected grades. At least one grade and one skill must remain checked to save settings.
- Every category has second-grade content. Letter names add alphabet order; case pairs combine case matching with alphabet order; first/last letters add initial and final blends/digraphs; spelling adds vowel teams and longer words; sight words use a separate bank. Counting adds hundreds/tens/ones and counting by 5, 10, and 100. Adding and taking away use two-digit calculations, including regrouping, with one missing result digit. Picture vocabulary uses definitions. Computer buttons add copy/paste/cut, redo, refresh, upload/download, and file actions. Computer basics adds input/output roles and Control shortcuts, with a written action cue for voice-off play. Algorithms add middle-instruction debugging, three-command repeats, events, loop order, and moving two steps through a plan. Answers still remain one letter, digit, picture, or symbol.
- **Computer basics** includes 27 kindergarten/first-grade challenges: ten pictured computer parts, seven part/function matches, five keyboard keys, and five actions such as save, open, print, undo, and help. Early levels use familiar parts, then jobs and basic keys; first grade adds Shift, Tab, saving, and folders. **Algorithms & order** starts with complete two-step picture plans and grows to four-step plans using first, then, next, finally, last, before, and after. First grade adds repeating commands, repeat counts, and three-by-three robot paths with a missing final arrow. Each skill has its own checkbox under Computers & thinking. Existing saved skill selections remain unchanged; enable the new skills in settings to include them in an existing player's next climb.
- The spider appears after a configurable number of misses in a **complete** recent-attempt window (default 3 of 5). It sits on a wrong answer, laughs only when that answer collapses under Pip, and moves to another wrong answer on reset when one is available. Narration replay does not move it.
- Synthesized cricket chirps begin after 15 seconds without input, then repeat every 60 seconds. Pip rubs his wings, rocks, and sends out musical notes for the 840 ms chirp burst, then returns to waiting. Any pointer/keyboard input resets that schedule and stops the singing pose. Reminders wait until the player can answer and are silent in a hidden tab or settings dialog. Garden sounds and narration have independent settings; reduced-motion preferences keep the illustrated singing pose without the wing motion.
- The personal best is the highest **successfully completed** level. Separate keys cover answer count, fall mode, selected grades and skills, and spider rules; theme and sound preferences do not split scores. Existing saves/settings without grade checkboxes keep the original K + first-grade progression and their existing best-score key. Enable second grade in settings to add it to a new climb. The five-level save records the chosen grades, and Continue restores them. Blocked storage falls back to memory for the current visit.

## Extending the content

`resources.ts` contains curated 3-, 4-, and 5-letter word banks, picture/emoji cues, common nouns, common verbs, sight words, letter pronunciations, navigation symbols, and the grouped skill checklist.

`discoveryResources.ts` holds computer parts/jobs/keys/actions, twelve complete picture plans, and direction tokens. `discovery.ts` owns the modular computer and sequencing generators. `QuestionClues.tsx` renders labeled instruction cards, a robot grid, repeat cues, and picture references with emoji fallbacks. The content follows the early instructions/sequencing approach in [ScratchJr's introduction](https://www.scratchjr.org/curricula/animatedgenres/1.pdf) and [Code.org Course A](https://studio.code.org/courses/coursea-2025/units/1?viewAs=Instructor); the questions and plans are original.

`secondGradeResources.ts` supplies separate word, vowel-team, vocabulary, button, input/output, and shortcut banks. `secondGrade.ts` supplies a generator for each of the twelve skills. Keeping these banks separate preserves previously seeded K / first-grade questions. Reference topics include second-grade [place value and arithmetic](https://www.thecorestandards.org/Math/Content/2/NBT/), [vowel teams](https://www.thecorestandards.org/ELA-Literacy/RF/2/3/b/), and [CSTA's grade-two sequence, event, and iteration concepts](https://csteachers.org/pk12standards/view/).

Each function in `engine.ts`'s `GENERATORS` or `secondGrade.ts`'s `SECOND_GRADE_GENERATORS` receives a seeded RNG and progression context, then returns a short prompt, separate spoken text, the correct token, a distractor pool, and optional visual clues. `questionFor` selects enabled skills in balanced shuffled rounds and chooses unique answers. To add a skill, add its checklist entry, `SkillId`, and generators for each grade; the animation and game loop need no changes. Keep written prompts at six words or fewer and arithmetic answers in 0–9.

`characters.tsx` and the scoped CSS supply scalable SVG cricket states (idle, chirp, charge, super-jump, jump, suspense, fall, landing, celebration), spider expressions, leaves, and two customizable themes. `audio.ts` contains browser speech and synthesized effects. There are no downloaded asset or font dependencies.

Computer illustrations reference the ten unmodified [Twemoji](https://github.com/jdecked/twemoji) SVGs hosted on jsDelivr, pinned to `v16.0.1`. Artwork by Twitter and other contributors, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); credits also appear in settings. No image-generation service or image downloads are used. Each reference retains its emoji until loading succeeds, falls back on error, and sends no referring page URL. Questions, speech, and saved progress continue to work when image hosting is unavailable.

Speech uses the device's available English voices. When speech is unavailable or errors, a timed reading gate remains and the game displays an explanatory status. Real voice quality and audio policy should also be checked on the intended iPad/phone browsers.
