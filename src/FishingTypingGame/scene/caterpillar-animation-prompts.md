# Caterpillar crawling animation prompts

Generated with the built-in ImageGen tool using each species' existing caterpillar illustration as its reference. Each sheet contains twelve separately generated crawling poses. Cropping, alignment, palette encoding, and pose extraction use the project scripts; they do not redraw the artwork.

## Monarch

Use case: scientific-educational. Asset type: twelve-frame transparent caterpillar animation sheet for an existing painted nature-field-guide game. Input image 1 is the exact character and painting-style reference. Create a new animation sheet of this same species, retaining its markings, colors, head shape, hairs or spines and species-correct legs. ONE exact regular FOUR-column by THREE-row grid of twelve equal cells, landscape aspect ratio 4:3. Transparent background throughout; NO checkerboard, ground, leaf, twig, cast shadow, captions, borders or grid lines. Each cell contains ONE complete side-view caterpillar, head consistently LEFT in all twelve frames (mirror the reference orientation if needed), common foot baseline, consistent scale, body centered, at least 12% empty margin on all sides and clear gutters. Read frames left to right across rows: show a smooth complete crawling/inching cycle, body extended -> hind prolegs grip and rear segments draw forward -> middle gently contracts and arches -> front thoracic legs reach and grip -> head and front extend -> rear follows -> return to the fully extended first pose. Twelve clearly distinct progressive anatomical poses, with a real traveling contraction, bending segments and moving feet, not twelve identical copies and not just translating a rigid image. Preserve the actual many prolegs of the supplied species, do not turn all caterpillars into two-legged geometrid loopers. Final pose leads smoothly back to first.
